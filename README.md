原备赛时间线记录了 2026 年 9 月的报名与校赛安排。相关早期节点现已过去；后续参赛、培训和答题安排应以主办方及学校最新通知为准。原始计划文档保留作历史记录，不再作为当前倒计时依据。

## 比赛全貌（一句话）

教育部高等学校图书情报工作指导委员会指导的**全国性大学生竞赛**，考核 **信息素养 + 数据素养 + AI 应用能力**。
校赛（个人）→ 省赛（团队：淘汰赛 + 作品）→ 全国联赛（线下，2026 年 11 月 26-27 日重庆大学）。

**省赛决赛总分 = 淘汰赛 × 30% + 决赛作品 × 70%** —— 作品是拿奖的关键。

## 备赛路线图

| 阶段 | 时间 | 关键动作 |
|---|---|---|
| 0️⃣ 报名 | ~09-17 | 确认学校通道、注册平台、入 QQ 群 |
| 1️⃣ 校赛备考 | 09-12 ~ 09-18 | 三素养速览 + 每日刷题（重点：信息检索 + AI 工具应用） |
| 2️⃣ 校赛 | 09-19 ~ 09-21 | 线上个人答题，稳过出线 |
| 3️⃣ 组队备战 | 09-22 ~ 10-11 | 组队注册省赛，淘汰赛刷题 + 锁定作品选题 |
| 4️⃣ 省赛淘汰赛 | 10-17 ~ 10-18 | 线上限时闯关：个人对抗 + 团队对抗 |
| 5️⃣ 决赛作品 | 10-19 ~ 11-02 | 开放主题作品 + 成果展示视频（70% 权重） |
| 6️⃣ 全国联赛 | 11-26 ~ 11-27 | 极速对抗 30% + 现场答辩 70%（省一择优推荐） |
