# 02 · 时间线作战计划

> 今日锚点：2026-09-11。全程以"拿省赛奖 → 冲全国联赛"为目标。
> 原则：**先保报名，再保校赛出线，主攻省赛作品（70% 权重）**。

- [ ] 加入官方 QQ 群，把群公告/培训通知读一遍

- [ ] 弄清本校校赛出线名额（前多少名组队省赛）

**交付物**：报名截图 + 官方通知存档到 `notes/`。

## Phase 1 · 校赛备考冲刺（09-12 ~ 09-18，共 7 天）

校赛是"竞赛系统随机抽题、在线答题"的个人赛，本质是**题库速成 + 反应速度**。

| 天数 | 任务 | 产出 |
|---|---|---|
| D1 | 通读 [03-study-guide.md](03-study-guide.md)，按考纲过一遍知识骨架 | 知识漏洞清单 |
| D2 | 信息检索理论 + 检索实操（知网等库实际练 20 个检索式） | 检索笔记 |
| D3 | 学术规范 + 信息资源（学术/政务库分类记忆） | 速记表 |
| D4 | 数据素养：统计基础 + 数据可视化常识 | 速记表 |
| D5 | AI 应用：提示词工程 + 主流 AI 工具能力边界 | 提示词模板库 |
| D6 | 全天模拟刷题（平台模拟题 + 往届题），**计时训练** | 错题本 |
| D7 | 错题复盘 + 重刷错题 + 考前速记表过一遍 | 可打印速记卡 |

**节奏建议**：每天 2~3 小时；刷题计时（每题限时，模拟真实抽题节奏）。

## Phase 2 · 校赛（09-19 ~ 09-21）

- [ ] 提前 30 分钟进场测试环境（浏览器、网络、收卷规则）
- [ ] 答题策略：先易后难，不会的标记跳过，最后回头
- [ ] 考后立即记录印象中没把握的题 → 补进错题本（可能省赛再现）

**交付物**：校赛成绩/晋级名单存档。

---

## Phase 3 · 组队 + 干掉省赛淘汰赛（09-22 ~ 10-11）

- [ ] 09-22 起，按校赛排名组队（3 人，技能互补：检索强 + AI 工具强 + 表达/PPT 强）
- [ ] 09-22 ~ 10-11 完成省赛队伍报名（09-22—10-11）
- [ ] 组内分工：每人负责一块题库领域，每周 2 次组队刷题
- [ ] 10-13 省赛淘汰赛培训（必须全员听）
- [ ] **10 月中**锁定决赛作品选题 + 分工（作品 70% 权重，要提前启动）

**交付物**：队伍报名记录 + 分工表 + 作品选题（三个候选，选一）。

---

## Phase 4 · 省赛淘汰赛（10-17 ~ 10-18）

- [ ] 赛前：组内统一速记表 + 对抗规则演练（个人对抗 + 团队对抗）
- [ ] 团队对抗要点：现场分工（抢题手 / 查证手 / 提交手），提前练 2 轮

**交付物**：晋级名单；若晋级直接进入作品闭关。

## Phase 5 · 省赛决赛作品（10-19 ~ 11-02 22:00）⭐ 得分主战场

权重 70%，**这是整个比赛胜负手**。计划（不能等，10-11 前就要定题）：

| 时间 | 任务 |
|---|---|
| 10-11 前 | 定题 + 作品大纲 + 数据/资料收集启动 |
| 10-19 ~ 10-24 | 作品主体完成 60%（用 AI 提速，但核心内容自研） |
| 10-25 ~ 10-28 | 完善 + 打磨 + 成果展示视频脚本 |
| 10-29 ~ 11-01 | 录视频 + 文档装订 + 内部评审（找老师/同学挑刺） |
| 11-02 | 最终提交（22:00 截止，提前 6 小时交，别卡点） |

详细作品思路见 [04-project-playbook.md](04-project-playbook.md)。
