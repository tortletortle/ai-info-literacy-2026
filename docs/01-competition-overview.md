# 01 · 赛事全貌

> 来源：大赛官方平台通稿、中国民航飞行学院图书馆通知（2026）等公开信息。以学校/官方通知为准。

## 是什么

由**教育部高等学校图书情报工作指导委员会**等指导、**大学生"AI+信息素养"大赛组织委员会**主办的全
国性大学生竞赛。前身是 2023 年西部大学生信息素养大赛，2024 年升级为全国赛，2026 为第四届。
核心理念：**找信息 → 判断信息 → 利用信息 → 用 AI 解决问题**。

## 赛道设置（2026）

| 赛道 | 说明 |
|---|---|
| 本科生 | 本通知对应赛道 |
| 研究生 | 同上 |

> 报名一般**以学校为单位**组织（图书馆/图工委牵头），个人不能直接报名，务必先确认本校名单。

## 比赛结构与评分权重

```
校赛（个人，线上）
  └─ 出线 → 组队报省赛
      省赛淘汰赛（线上限时闯关：个人对抗 + 团队对抗）  → 团队总成绩排序晋级
      省赛决赛（开放主题作品 + 成果展示视频）
      省赛总分 = 淘汰赛 × 30% + 决赛作品 × 70%        → 评省赛一/二/三等奖
              └─ 省赛一等奖择优推荐
                  全国联赛（线下·重庆大学）
                  联赛总分 = 极速对抗 × 30% + 专家打分 × 70%
```

## 考核内容（三段式）

1. **信息素养**：信息检索理论、学术/政务信息资源、学习科研工具、学术写作规范
2. **数据素养**：数据获取、清洗、分析与可视化、数据伦理与安全
3. **AI 应用能力**：AI 工具使用、人机协作、用 AI 解决真实问题的完整链路
