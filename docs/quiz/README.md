# QuizMind AI · Web Quiz V0.1

## 当前状态

这是静态网页答题台的第一版，部署目录为 \`docs/quiz/\`。

已实现：

- 独立资料整理页（`admin.html`）：在浏览器本地读取可选中文本的 PDF/TXT，抽取官方样题结构。
- 候选题默认 pending；逐题核对题干、选项、答案、解析和原文页码后，才能勾选为 verified。
- 导出 JSON 后可在答题台导入；原文页码与摘录会随题目保留。

- 粘贴题干与选项。
- 支持按编号或空行拆分多道题。
- 识别 A-H 选项，并进行题干/选项相似匹配。
- 只对 \`reviewStatus: "verified"\` 的题目输出答案。
- 按选项内容映射答案，降低选项顺序变化造成的错误。
- 显示题库来源、资料日期和解析。
- 支持从 JSON 文件导入题库，导入内容保存在当前浏览器 localStorage。

已建立资料索引：

- `data/modules.json`：官方命题范围的 9 大类、50 个知识模块目录。
- `data/sources.json`：官方平台与高校图书馆公开通知的来源登记、权威等级和证据使用规则（含附件访问限制记录）。
- `data/competition-format.json`：由高校图书馆官方通知交叉核验的校内选拔赛题型与分值结构（不外推到其他赛段）。
- `api-contract.json`：后续服务端答题 API 的请求/响应契约。
- `ARCHITECTURE.md`：证据优先答题流程、来源等级、多选题判定与验收指标。

尚未实现：

- 扫描版 PDF OCR（当前只支持 PDF 内嵌文本）。
- 对任意网页/课件的通用知识抽取；当前解析器针对官方命题文件的样题格式。

- 自动抓取网页/PDF/课件。
- OCR 图片识别。
- LLM 未知题推理。
- 实时网页查证。
- 多用户云端题库同步。

未命中时不猜答案。这是有意设计的防幻觉策略，不是答题失败后静默返回随机结果。

来源规则：赛事官方平台作为 A 级首要来源；高校图书馆官方通知及附件作为 B 级交叉核验来源；第三方整理仅作为检索线索，不能单独支撑标准答案。动态页面、数据库和产品功能题必须记录实际访问日期与页面证据。

## 题库 JSON 格式

\`\`\`json
{
  "schemaVersion": 1,
  "questions": [
    {
      "id": "Q001",
      "stem": "题干文本",
      "type": "single",
      "options": [
        { "key": "A", "text": "选项 A" },
        { "key": "B", "text": "选项 B" }
      ],
      "answer": ["A"],
      "explanation": "答案解析",
      "source": {
        "title": "官方资料名称",
        "url": "https://example.org/source",
        "updatedAt": "2026-11-23"
      },
      "reviewStatus": "verified"
    }
  ]
}
\`\`\`

注意：

- \`answer\` 引用的是题库原始选项的 key。
- 题库中选项必须保留完整文本。
- 只有经过人工/规则审核的题目才能设置 \`reviewStatus: "verified"\`。
- 未审核题目可设置为 \`pending\`，不会参与自动答题。
- 来源链接必须指向真实、可访问的材料；不得虚构来源。

## 本地运行

在仓库根目录执行：

\`\`\`bash
python -m http.server 8000
\`\`\`

浏览器打开：

\`\`\`
http://localhost:8000/docs/quiz/
\`\`\`

直接双击 HTML 可能因浏览器对本地 JSON fetch 的限制而无法加载内置题库，建议使用本地 HTTP 服务。
