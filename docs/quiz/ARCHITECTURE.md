# QuizMind AI 桌面端架构与验收原则

## 产品边界

QuizMind AI 以 Windows 桌面应用为正式交付形态。浏览器版仅作为次级预览与兼容验证入口。应用把本地题库、PDF/TXT 知识资料、模型连接配置和证据审计整合到一个可离线运行的桌面工作区；只有调用云端模型时才需要网络。

## 总体数据流

~~~mermaid

  A["导入官方 PDF/TXT"] --> B["本地文本提取与页码保留"]
  B --> C["候选题抽取"]
  C --> D["人工核对来源、题干、选项与答案"]
  D --> E{"A/B 来源且元数据确认？"}
  E -->|否| F["仅保存为知识线索 / 待审核"]
  E -->|是| G["保存到本地已审核题库"]
  H["粘贴题目"] --> I["题型识别与选项解析"]
  I --> J{"本地已审核题库命中？"}
  J -->|是| K["题干相似度与选项文本对齐"]
  J -->|否| L["本地知识库检索"]
  L --> M{"每个选项都有直接证据？"}
  M -->|是| N["主进程调用模型并校验逐项证据 ID"]
  M -->|否| O["拒绝猜测 / 标记不确定"]
  K --> P["答案、解析、来源与页码"]
  N --> P
  O --> P
~~~

## 五类核心数据

1. **原始资料**：用户导入的官方 PDF/TXT，原文件不上传；抽取文本按页保存。
2. **知识资料**：来源 ID、标题、URL、等级、修订版、页码和文本。
3. **候选题目**：从资料抽取的题干、选项、候选答案与解析，默认 pending。
4. **审核题库**：只有用户明确核对并确认来源元数据、且来源等级为 A/B 的题目才允许 verified。
5. **证据记录**：模型对每个选项必须单独给出 evidence IDs；引用必须属于本次提供的资料集合。系统只验证引用结构和 ID 存在性，不等同于自动证明原文在语义上蕴含该判断；用户仍需核对原文。

## 答题路由

- **L1 本地题库**：只匹配 verified 题目；题干相似度、选项文本对齐和歧义检查均通过才返回。
- **L2 本地知识检索**：按题干与选项检索本地 PDF/TXT 页段，最多选择有限证据片段。
- **L3 AI 逐项推理**：只把已确认的 A/B 级资料片段发送给配置的 OpenAI-compatible 模型；每个选项需要独立证据引用。系统检查引用 ID 有效性，但不宣称自动完成语义蕴含证明。
- **拒答**：证据不相关、选项分析不完整、缺少引用或答案集合不符合题型时，返回 uncertain。
- **后续实时查证**：尚未实现；不能把本地资料检索描述为实时联网查证。

## 来源等级

- **A**：赛事主办方及官方平台原始资料，可作为最终答案依据。
- **B**：高校图书馆等学校官方通知及附件，用于交叉核验、定位主办方资料。
- **C**：第三方转录、博客、社区讨论，仅作线索，不能单独支撑标准答案。

来源等级只是资料分类，不自动证明某个文件真实。导入时默认 C 级；用户必须主动选择 A/B，并勾选确认所选文件与来源元数据一致。已核验题目还必须保存来源 ID、标题、页码和原文摘录。

## 桌面端安全边界

- Electron renderer 开启 contextIsolation、sandbox，关闭 nodeIntegration。
- 只通过 preload 暴露窄 IPC 接口；renderer 不接触 API Key。
- API Key 通过 Electron safeStorage 使用操作系统安全存储加密。
- 远程模型端点强制 HTTPS；仅允许 localhost 回环地址使用 HTTP。
- 本地文件通过受限 app://quizmind 协议读取，阻断路径穿越和跨源导航。
- 工作区写入由主进程进行 schema、来源、页码、重复 ID 和体积校验。

## 验收指标

| 指标 | 验收方法 |
|---|---|
| 本地题库准确率 | 留出集逐题核对，记录误命中和拒答 |
| 选项乱序映射 | 随机重排选项后按文本对齐 |
| 多选集合准确率 | 必须完整集合完全一致 |
| 逐项证据覆盖率 | 每个选项有有效来源 ID、页码和原文片段 |
| 来源晋级安全性 | C 级、无元数据确认或无原文页码不得进入 verified |
| PDF 抽取质量 | 按页检查乱码、阅读顺序和跨栏混排 |
| 拒答质量 | 缺证据问题不得输出伪确定答案 |
| 数据持久性 | 重启后读取、重复导入合并、备份后恢复 |
| 桌面构建 | Windows CI 构建 NSIS 与 portable，并进行实体机启动验收 |

## 当前实现边界（V0.2）

已实现 Windows Electron 桌面框架、模型设置与密钥加密、本地工作区持久化、PDF/TXT 文本抽取、候选题人工审核、一键保存、逐项证据引用和 Windows 安装包/便携版构建。正式审核题库仍为空，50 个模块仍待与可核验的官方附件逐项比对。扫描版 OCR、官方域名实时检索和动态页面验证尚未实现。
